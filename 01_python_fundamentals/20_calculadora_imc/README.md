# 20 - Calculadora de IMC

## Objetivo

Calcular IMC e classificar faixa de peso.

## Enunciado

Le peso e altura, calcula IMC e classifica (abaixo do peso, normal, sobrepeso ou obesidade).

## Resolucao (retorno 05/08)

Funcoes `ler_dados`, `calcular_imc`, `classificar_imc` e `exibir_resultado`. Valida massa/altura positivas. Faixas encadeadas (`< 18.5`, `< 25`, `< 30`) sem buracos.

## Como executar

```bash
cd "20_calculadora_imc"
python main.py
```
