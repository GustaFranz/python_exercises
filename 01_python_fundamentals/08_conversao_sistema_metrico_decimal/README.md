# 08 - Conversao do sistema metrico decimal

## Objetivo

Converter metros para unidades do sistema metrico decimal.

## Enunciado

Recebe valor em metros e converte para km, hm, dam, dm, cm e mm.

## Resolucao (retorno 30/07)

Troquei os 6 calculos soltos por um dicionario de fatores + funcoes (`ler_metros`, `converter_metros`, `exibir_conversoes`). Valida negativo com `raise ValueError`. Mesmo resultado, codigo mais facil de manter.

## Como executar

```bash
cd "08_conversao_sistema_metrico_decimal"
python main.py
```
